# OpenSCAD + JustinSDK Feature Plate

This repository demonstrates:

- a `.scad` entrypoint
- package-style library imports like `use <@justinsdk/src/starburst.scad>`
- JustinSDK modules driving both the base lattice and the raised centerpiece

Suggested linked libraries:

- `justinsdk`
